# Proposal

## What will (likely) be the title of your project?

# Musical Geoboard

## In just a sentence or two, summarize your project. (E.g., "A website that lets you buy and sell stocks.")

My software project will be a [geoboard](https://apps.mathlearningcenter.org/geoboard/) with which the user can draw shapes that correspond to different audio parameters and generate audio data.

## In a paragraph or more, detail your project. What will your software do? What features will it have? How will it be executed?

I plan to create a geoboard with a grid on which shapes can be drawn. The positions on the grid will correspond to parameters such as pitch and note length. I will need to develop or import a database of stock sounds that can be generated and whose parameters can be changed in real time. I want to allow recording function, with audio exports. All of this will be executed using JavaScript.

### In a sentence (or list of features), define a GOOD outcome for your final project. I.e., what WILL you accomplish no matter what?

- Create a geoboard with a grid and nodes that traverse shapes drawn by the user.
- Develop or import stock sounds whose parameters can be changed in real time.

### In a sentence (or list of features), define a BETTER outcome for your final project. I.e., what do you THINK you can accomplish before the final project's deadline?

Audio recording and export function in addition to the aforementioned outcome.

### In a sentence (or list of features), define a BEST outcome for your final project. I.e., what do you HOPE to accomplish before the final project's deadline?

I hope to develop a nice UI component for my project that would elevate it to a viable tool for music and audio generation, and potentially MIDI data generation and export.
